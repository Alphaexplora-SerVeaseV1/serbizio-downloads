# Serbizio downloads

Early-access builds of the Serbizio apps, published here until they are live on Google Play and the App Store.

## Serbizio (for customers) — Android

**[Download the latest version](https://github.com/Alphaexplora-SerVeaseV1/serbizio-downloads/releases/latest/download/serbizio-customer.apk)**

## Serbizio Provider (for service experts) — Android

**[Download the latest version](https://github.com/Alphaexplora-SerVeaseV1/serbizio-downloads/releases/latest/download/serbizio-provider.apk)**

Service experts need an approved application before they can sign in. Apply on the Serbizio website first.

## How to install

1. Open the download link on your Android phone and download the file.
2. If your phone asks, allow your browser to install apps.
3. Open the app, then sign in or create an account.

Earlier versions are listed under [Releases](https://github.com/Alphaexplora-SerVeaseV1/serbizio-downloads/releases).

## For the Serbizio team

This repository only holds release files. The source code lives in the private Serbizio repositories.

Every release must include **both** current APKs, named exactly `serbizio-customer.apk` and `serbizio-provider.apk`, and be marked as the latest release. The download links above and the Serbizio website always serve files from the latest release, so a release missing one of the APKs would break that app's link.
